# Simulação de dinâmica molecular: Potencial de Lennard-Jones
**Integrantes:**
- Élyda Rodrigues de Oliveira
- Gabriel Henrique de Souza Magalhões
- Fellipe Carreiro de Oliveira

Esté projeto foi desenvolvido para a disciplina de Computação de Alto Desempenho na UFRRJ(Universidade Federal Rural do Rio de Janeiro).
O objetivo deste projeto foi de desenvolver uma simulação de dinâmica molecular, inspirado do [DL_POLY](https://ccp5.gitlab.io/dlpoly/Introduction.html) 
em apoio ao artigo: **Performance analysis of a hybrid MPI/OpenMP application on multi-core clusters**.

---

## Tecnologias Utilizadas

- Linguagem/Framework:
  - Linguagem C
  - MPI(Message Passing Interface)
---
## Máquina Usada
- AMD Ryzen 5 5600X 6-Cores, 12 Threads
- 2x 64-bit DDR4 32GB  1600MHz
- Kingston M.2, NVMe, Leitura: 6000 MB/s e Gravação: 4000 MB/s
